双击 demo/index.html。依次查看专业背景、案例流程、案例演示。

【石油背景】
更多孔道、更深穿透可能降低近井阻力，也可能增加出砂倾向和成本。在完井方案内应同时比较产能与风险，而非只追最大产量。

【智能介入】
双代理与帕累托搜索 · 石油工程可视化实验
<h3>智能方法如何介入？</h3><p>二阶岭回归双代理分别预测归一化产能和出砂倾向；枚举孔密、相位、穿深，筛掉超风险与预算方案，再求最大产能/最小风险的帕累托前沿。</p><div class="formula">强度 / 预算 / 风险容忍 → 双目标代理 → 非支配方案集 → 对照与复核</div><div class="formula">产能参考=0.45+0.55d+0.5l−0.2d²−0.12l²−0.035p²+0.08s；d=孔密/20，l=穿深/0.75，p=(相位−90)/30</div>

【数据与边界】
<h3>数据来源与评价隔离</h3><p>500个训练、120个独立测试参数组合，地层强度也作为特征；训练标签来自公开声明的教学响应面。</p><p>合成训练和测试采用独立随机种子。参考标签仅用于训练或测试评价，不进入预测函数。真实应用需工程专家标注、独立工区验证与误差审查。</p>
<b>模型边界与来源</b><p>孔密4—20孔/m，相位60/90/120°，穿深0.15—0.75m为教学候选范围；风险为模拟倾向分，不是现场概率。</p><p>石油概念参考：<a target="_blank" rel="noopener" href="https://glossary.slb.com/terms/c/completion">SLB专业资料</a>。全部公式、阈值、范围为本例声明的教学假设；不用于实际施工参数审批。</p>
数据全部为合成与简化机理，不能将演示分数当真实油田效果。
