READ THE SUBSURFACE

地层本来连续，断层让它错开。

地震反射像地下的“条纹”：同一条纹代表相近的反射界面。岩层沿断裂面滑动，条纹就在两侧出现错位。解释断层，是为了认识构造分隔与储层连通性，为后续井位部署提供约束。

① 从岩层，到反射剖面

砂岩可提供储集空间；断层可能导通，也可能封堵。识别出断层 ≠ 发现油气，还需结合岩性、流体与压力证据。

② 看“错位”，而不是只看亮点

已知断层位置 红蓝表示反射振幅正负

横轴为地震道，纵轴为双程旅行时（TWT）。纵向是时间，不能未经速度模型直接解释为深度。条纹的中断、错位与局部不连续是机器学习的输入证据。

业务问题

逐剖面追踪，容易漏掉弱断层

人工需关联多条剖面。低信噪比、褶皱和处理伪影会让解释不一致。

智能介入

图像特征 → 像素分类

本例用可训练的逻辑回归融合不连续属性；工程可扩展到三维 U-Net 等语义分割网络。

人的价值

从全图描线，到重点复核

概率图提示候选区域。专家核查误检、漏检和跨剖面连续性，再纳入构造模型。

数据与边界

本例程序生成二维层状反射、单条断层、随机噪声和二值掩膜；没有使用真实油田数据，也没有加载预训练网络。概率是分类分数，未经真实工区校准。教学标签宽度为距断层中心线 ±2 道；所有指标使用相同定义。参考：Wu 等，FaultSeg3D（2019），作者代码与论文入口。该文提供合成数据训练三维 CNN 的研究方向，本案例自行实现二维轻量教学方案，非论文复现。

不用“准确率”掩盖漏检

断层像素占比很低，全预测成背景也可能有很高准确率。

Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
F1 = 2TP / (2TP + FP + FN)
IoU = TP / (TP + FP + FN)

提高阈值通常减少误报，但可能漏掉更多断层；阈值应在验证集确定，测试图调参仅用于课堂敏感性观察。

建议试验路径

① 默认参数训练，记录 F1 与误差图；② 保持权重不变，把噪声调到 0.65，观察误检；③ 把位移调到 0，测试无断层负样本；④ 提高阈值，比较误报与漏报；⑤ 更换剖面，观察泛化。无断层时 Recall 标为“不适用”；没有预测正类时 Precision 同理。CSV 可下载为答辩证据。
