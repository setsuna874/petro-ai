物探-地震断层自动解释 | 首个案例试作 v1.0.0

学号末两位15：(15-1)%13+1=2，对应物探。
本例是物探五个完整案例之一，其余四例各有独立案例压缩包。
物探必做清单：地震断层自动解释、地震相智能分类、初至波自动拾取、储层参数反演、地震资料噪声压制。

一、运行与导入
1. 先解压本压缩包。
2. 双击 fault-interpretation-case/demo/index.html 可独立运行全部三部分，无需网络或后端。
3. 打开老师的门户 index.html，点击“＋ 添加案例”，选择或拖入整个 fault-interpretation-case 文件夹。
   原门户接收的是解压后的文件夹，不是ZIP本身。
4. 所属场景应自动识别为“物探 / 地震断层自动解释”（sceneId=s1）；校验通过后点击“校验并添加”。
5. 门户中依次查看“专业背景 / 案例流程 / 案例演示”；演示内也有三章节。
6. 导入内容存入当前浏览器；换设备需重导。单包远小于6MB，无第三方CDN。
7. 在线门户已预装一个不同ID的预览插件；再上传本包时将优先显示新导入案例，不产生同ID冲突。

二、推荐的90秒试验
进入演示 → 点击“03 案例演示” → 训练模型 → 观察损失、权重、F1与误差图。
提高噪声至0.65 → 比较误检；调整阈值 → 比较Precision/Recall；位移调为0 → 测试无断层。
点击图像查询像素 → 更换测试剖面 → 导出CSV；重置回默认数据和阈值（保留模型权重）。
每次重训使用同一批训练数据，因此结果可重复。新测试数据不参与训练。

三、关键亮点与边界
- 石油背景：错断的地层剖面、反射界面与构造连通性；明确断层识别不等于发现油气。
- 流程：五步可点击输入输出卡片，避免只有一张流程图而没有步骤解释。
- 数据分析：三图联动、概率热图、TP/FP/FN着色、像素探查、损失曲线、权重条图、阈值扫描、CSV。
- 真机器学习：类别平衡加权逻辑回归，在浏览器通过梯度下降训练。不是深度学习模型，不加载假权重。
- 诚实评价：独立剖面测试，与固定不连续度阈值基线比较；不保证每个条件下模型更优。
- 合成数据：单断层二维周期反射，仅示范算法要点。概率未经校准，不是生产解释工具。

四、可复现细节
128×96网格，采样4ms；标签为距断层中心±2道；边缘9像素不评估。
6幅训练剖面种子101—106；噪声0.05—0.30，时移5—14采样点；测试种子2026起。
特征为归一化不连续度、最佳相关的绝对相位错移、差能量、纵向邻域不连续均值。
保留所有断层像素，以固定种子抽取8%背景，正负类别分别加权；150轮梯度下降，学习率0.6，非偏置L2系数0.002。
无额外校准/验证/早停。模型权重中不包含坐标或断层参数，特征计算不读取truth。
固定基线：不连续度≥0.50。模型阈值默认0.50，可调；调参仅用于课堂可视化。
指标无额外容差匹配。没有真实断层时Recall=NA，没有预测正类时Precision=NA；空集F1/IoU记0。
