【导入原门户或新版门户】
解压ZIP → 点击“＋ 添加案例” → 选择整个 completion-select-case 文件夹 → 校验并添加。

【离线运行】
双击 demo/index.html。依次查看专业背景、案例流程、案例演示。
方法会自动运行；可调参数，点击“运行 / 重新计算”重训或重新搜索，导出当前结果CSV。
重置将恢复参数并重新运行；“更换测试数据”更新独立测试/井身几何或初始状态；固定案例库的方式优选不显示此按钮。

【石油背景】
裸眼、套管射孔、筛管和砾石充填对产能、防砂、隔离和成本的侧重不同。把地层特征与邻井证据组织成可追溯关系，可帮助方案排序。
