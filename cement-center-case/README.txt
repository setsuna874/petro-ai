【石油背景】
偏心使环空间隙不均匀，窄边顶替困难。先把井径、套管和井斜变成居中度曲线，再把有限扶正器优先放在困难段。

【智能介入】
几何评价与组合优化 · 石油工程可视化实验
<h3>智能方法如何介入？</h3><p>几何计算 + 贪心组合优化：逐个插入能最大提升最差居中度的位置；邻域交换改进，并保留同数量等间距起点中更好的方案。</p><div class="formula">井径 / 井斜 → 组合搜索安放 → S=(a−e)/a → 对照与复核</div><div class="formula">S=(a−e)/a；a=(井径−178)/2；优先提升最差S</div>
