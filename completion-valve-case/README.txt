【石油背景】
三段储层共享地面产液处理能力。高含水段全开会挤占油产能；阀门控制要在油量、水量、切换代价和未来状态之间平衡。

【智能介入】
表格Q-learning分段控制 · 石油工程可视化实验
<h3>智能方法如何介入？</h3><p>真实表格Q-learning：每段含水率离散三档形成27个状态，8种开/半开动作；在简化动态环境训练，独立初始条件比较全开与固定规则。</p><div class="formula">三段含水 / 开度 → 学习动作价值 → 油水与开度时序 → 对照与复核</div><div class="formula">Q(s,a) ← Q(s,a)+0.15[r+0.92maxQ(s′,a′)−Q(s,a)]；r=油量−水惩罚×水量−2×切换数</div>

【可视化】
背景有井筒/压力/孔道等SVG概念图，流程有五步输入输出图解；演示有动态结构图、四幅结果图、现场计算指标与证据表。

【数据与边界】
<h3>数据来源与评价隔离</h3><p>训练450个30步回合；种子独立测试30步，每步为教学时间单元。奖励=油量−水惩罚×水量−切换成本。</p><p>合成训练和测试采用独立随机种子。参考标签仅用于训练或测试评价，不进入预测函数。真实应用需工程专家标注、独立工区验证与误差审查。</p>
<b>模型边界与来源</b><p>不接真实储层模拟器。状态未包含压力衰竭和前一动作，属于简化/部分可观测近似；学习策略不保证优于规则或全开。</p><p>石油概念参考：<a target="_blank" rel="noopener" href="https://www.slb.com/products-and-services/innovating-in-oil-and-gas/completions/well-completions/intelligent-completions">SLB专业资料</a>。全部公式、阈值、范围为本例声明的教学假设；不用于实际施工参数审批。</p>
数据全部为合成与简化机理，不能将演示分数当真实油田效果。
几何优化和案例推理不伪装成训练神经网络；机器学习案例有独立测试，优化有基线及不可行结果，滑套策略有全开与规则对照。
