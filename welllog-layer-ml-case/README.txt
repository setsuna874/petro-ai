测井-测井曲线智能分层 | v1.0.0 | 2026-11-05
学号末两位15，对应测井类别；绑定场景 w1。

【如何导入】
1. 解压本ZIP，保留整个 welllog-layer-ml-case 文件夹。
2. 打开老师门户根目录 index.html，用Chrome或Edge。
3. 点击“＋ 添加案例”→选择文件夹→选整个 welllog-layer-ml-case。
4. 检查0项错误，点击“校验并添加”；所属场景应为“测井 / 测井曲线智能分层”。
5. 依次查看专业背景、案例流程、案例演示。
门户接收解压后的文件夹，不是ZIP本身。不要只选case.json，否则会丢失演示资源。

【独立运行】
双击 demo/index.html 即可离线运行三部分内容，无后端、无网络依赖。
案例演示→训练/拟合模型→按图示调参→更换独立测试数据→导出CSV。
重置按钮只重置测试条件/界面控件，已拟合模型保留；改变训练参数需点击重训。

【亮点】
地层界面，常藏在多条曲线共同的转折里。
测井仪器沿井筒记录岩石物理响应。分层把连续曲线切成待解释的地质单元，为储层评价、射孔选段与邻井对比提供候选界面。边界是解释证据的组合，不能把所有噪声尖峰都视为新地层。
交互路径：① 训练分类器；② 对照三条曲线和绿/红界面；③ 调噪声、阈值、最小间距；④ 按深度查询；⑤ 导出界面分数与候选表。
五步流程：曲线对齐 → 提取转折属性 → 训练界面模型 → 界面筛选 → 一对一匹配

【真实计算与边界】
使用带标签合成数据的监督学习，独立测试，提供基线；未下载模型权重，未使用真实油田数据。
演示中的参数和指标均由本地JavaScript现场计算，无固定成绩或假动画。
模型代码在demo/demo.js，通用数值求解在demo/runtime.js；固定随机种子便于复现。
测试真值不进入预测函数；只用于误差图和评价。教学合成高分不代表真实工区水平。
详细数据规模、指标定义、适用边界与参考链接见专业背景页面。
